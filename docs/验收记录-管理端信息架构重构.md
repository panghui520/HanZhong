## 4. 新增业务接口（**只加了 1 个端点**）

```
GET /api/admin/ops/business?type={scenic|rural|food|lodging|product}&range={TODAY|LAST7|LAST30|ALL}
```

- 权限：`/api/admin/**` 自动继承 `hasRole("OPERATOR")`。
- 返回：`range` / `range_from` / `range_to` / `period_label` / `kpis` / `top` / `trend` /
  `districts` / `scatter`（仅 scenic·rural）/ `distribution`。
- 无客流数据时返回**结构完整的零值**（`period_label="暂无客流统计（仿真）"`），
  **不是 500** —— 页面上给不出解释的错误最难排查。
- 5 个页面共用（驾驶舱第二层 + 四个业务页）。

**KPI 口径（后端已格式化，前端不再加工）**：

| type | KPI |
|---|---|
| `scenic` / `rural` | 到访（人次）· 平均承载率（%）· 高负荷资源（个）· 风险事件（条） |
| `food` / `lodging` | 资源数（个）· 客流（人次）· 承载均值（%）· 高负荷资源（个） |
| `product` | 农产品销售额（元）· 购买笔数（笔）· 乡村复购率（%）· 产地数（个） |

## 6. 数据来源与统计口径（**不新增第二套数据**）

| 用途 | 来源 |
|---|---|
| 客流 | `poi_visit_stats.visitors` |
| 销售 | `poi_visit_stats.purchases` × `product.price`（产地均价） |
| 复购 | `SUM(repurchases) / SUM(purchases)`（**笔数比，非用户级**） |
| 承载 | `poi_visit_stats.capacity_usage`（窗口**平均**，沿用 `avgUsageByPoi`） |
| 订单 | `orders` / `order_item` |
| 风险 | `risk_event` |
| 图片 | `poi_image` / `site_banner` |
| 评论 | `poi_comment` |

- 客流 / 销售是**合成数据**（`synthetic=true`）；景点评论 `poi_comment` **不是**（真实用户提交）。
- **严禁**新增 mock / synthetic / 前端硬编码经营数字。**没有数据就减少图表。**
- 餐饮 / 住宿的 `FOOD`(6) / `LODGING`(4) 行**本来就在 `poi` 表里**，缺的只是入口。
