## 一、这一页是什么

把网站**现有的全部景点**按真实经纬度铺在高德地图上，点标注看卡片、从卡片进现有的景点详情页。

**它没有自己的数据源。** 所有数据都来自现有接口：

| 用到的 | 来自 | 说明 |
|---|---|---|
| 景点（42 个，含经纬度/分类/区县/简介） | `GET /api/pois` | 与「探索汉中」页**同一个接口、同一份 `citypack/hanzhong/pois.json`** |
| 景点配图 | `GET /api/media/poi-images/covers`（经 `useCovers()` / `PoiImage`） | 没传图的景点回落手写 SVG 插画，与列表页同一套行为 |
| 城市中心（地图初始中心） | `GET /api/city` 的 `center` | 不写死坐标 |
| 景点详情页 | 路由 `/poi/:id` | 「查看详情」直接跳过去，没有新建页面 |

**后端零改动**：`/api/pois` 与 `/api/media/**`（GET）在 `SecurityConfig` 里本来就是 `permitAll`。

## 二、关键设计

### 2.1 两个高德 key 不能混用，前端这个必须进前端

`.env` 里现在有三个高德相关的值，**是两种不同类型的 key**：

| 变量 | 高德侧的类型 | 用在哪 |
|---|---|---|
| `AMAP_KEY` | **Web 服务** | **只在 Python 侧**（POI 搜索 / 地理编码） |
| `VITE_AMAP_JS_KEY` | **Web 端 (JS API)** | **必须进前端** —— 地图由浏览器直接加载 JS API |
| `VITE_AMAP_JS_SECURITY_CODE` | JS API 2.0 的**安全密钥** | 同上，必须在加载脚本前设置 |

- 原来的键名是 `JS_API_KEY` / `JS_SECURITY_CODE`，**改名成 `VITE_` 前缀，值一个字符没动**。
  原因是 Vite 的硬规则：只有 `VITE_` 前缀的变量才会被内联进产物。
  写成别的名字，`import.meta.env.JS_API_KEY` 恒为 `undefined`，症状是"地图白屏 + 报 key 无效"，
  很容易误判成 key 本身有问题。
- JS API key 藏不住也**不该藏** —— 它只能调用地图/标注/地理编码这类前端能力，
  无法调用服务端接口。真正需要保密的 `AMAP_KEY` 仍然只在 Python 侧。

### 2.2 `envDir: '..'`：一份 `.env` 三端共用

仓库里只有根目录一份 `.env`，而 Vite 默认只读 `web/` 下的。若沿用默认行为，
就得在 `web/` 下再放一份 —— 两份的结果是"改了根的那份、前端没变"，一个只能靠现象猜的静默不一致。

安全性由 Vite 自己的规则保证：**只有 `VITE_` 前缀的变量会被内联**。
这条是敢把 `envDir` 指向上层目录的前提，**已实测核对**（见 4.2）。

### 2.3 自定义标注：为什么拼 HTML 字符串，样式为什么不能 scoped

标注是 `AMap.Marker` 接管的（把字符串或 DOM 交给 `content`，之后由高德的渲染循环定位）。
在这上面套一层 Vue 组件，就要处理"Vue 的渲染时机"与"高德的重挂载时机"两套生命周期，
而这里需要的能力只有"换一段 HTML"。**代价是拼进去的文本必须自己转义** ——
所以 `format.ts` 新抽了 `escapeHtml`，`mapPin.ts` 用它，而不是各处自己写一遍转义。

**连带后果（很容易踩）：`.mpin*` 的样式不能写在 `<style scoped>` 里。**
scoped 的做法是给组件模板里的元素加 `data-v-xxx` 再靠属性选择器命中，
而 pin 的 DOM 是高德在**运行时**插进地图容器的，拿不到那个属性 ——
写在 scoped 块里**一条都不生效**，表现是"标注裸着显示"，且不报任何错。
所以 `InteractiveMap.vue` 末尾有一个**非 scoped** 的 `<style>` 块专放 pin 样式，
类名统一 `mpin` 前缀。这一节在文件里有独立注释。

标注本身：每个业态一个线性图标（山 / 屋 / 叉刀 / 床 / 车 / 袋）+ 一个按业态上色的圆点 +
一个指向坐标点的小三角。用图标而不是纯色圆点，是因为 42 个点铺在一张图上，
只靠颜色区分业态要求用户先记住"哪个颜色是住宿"。名称气泡**绝对定位** ——
它若参与 `.mpin` 的高度，`anchor: 'bottom-center'` 这个定位基点就会被带偏，
标注会整体浮在坐标点上方一段距离。

### 2.4 逆地理编码是**可选增强**，不是必需路径

数据包里的 POI 只有区县，没有门牌级地址，而需求里有「地址」这一项。
所以卡片打开时用高德 JS API 的 `Geocoder` 逆地理编码补一条街道地址：

- 拿不到就**回落显示区县 + 坐标**（卡片不会转圈、不会空一块）；
- 有**防竞态**：连点两个点，先发的请求后回来会把地址安到错的点上，所以记了 `addressFor`；
- `AMap.plugin` 只保证"插件可用"，**不保证授权通过**，真正的失败在 `getAddress` 的 status 里，两处都兜了。

实测有效：`南郑·黄官茶园` → `陕西省汉中市南郑区濂水镇`。

### 2.5 筛选只列**数据里真有的**业态

与「探索汉中」页同一套做法：`SHOPPING` 目前 0 个景点，所以它不会出现在筛选条里 ——
硬列出 6 个业态而其中 1 个是空的，点下去得到空白地图，等于让用户去发现一个不存在的东西。

### 2.6 视野留白跟着"卡片是否展开"走

`setFitView` 的右侧留白原来是固定的 380px（为右侧卡片留位）。实测那样会**多框进陇南、巴中**
这些邻省区域 —— 看起来不像一张"汉中地图"。改成 `active ? 400 : 70`：
卡片没开时不白缩一档，卡片开着时不让东边的点被压住。

另外：**只在"换筛选"和"重置视野"时 fit**，点标注改用 `setZoomAndCenter` ——
每次点标注都重新 fit 会让地图乱跳。

## 五、这一轮踩的两个坑（都很费时间，记下来）

### 5.1 探针用合成 `dispatchEvent` 点不动高德的标注

第一版探针用 `dot.dispatchEvent(new MouseEvent('click', { bubbles: true }))` 点标注，
**卡片永远不出现**，看起来像"点击功能坏了"。

真因：**高德 2.0 的标注不走普通 DOM click 监听**，它由自己的事件系统处理，
而那个系统吃的是真实输入（mousedown / mouseup / 鼠标位置）。
改用 CDP 的 `Input.dispatchMouseEvent`（`mouseMoved` → `mousePressed` → `mouseReleased`）
后立刻通过。

顺带一条：42 个标注必有重叠，**直接取第一个 pin 可能点到上面那个**，
断言"卡片名称 === 被点标注名称"就会假红。所以要遍历 pin、
用 `document.elementFromPoint(x, y)` 挑一个**没被遮挡**的。

### 5.2 模板字符串里注释中的反引号，会静默把表达式变成 `NaN`

回归脚本第一次跑，第 3 段报：

```
Failed to deserialize params.expression - BINDINGS: string value expected at position 19
```

离真正的原因很远。真因是那一版在**模板字符串内部**写了这样的注释：

```
    // 渲染后不该再有字面的星号（`**` 应该已经变成 <strong>）
```

反引号**提前终止了模板字符串**，剩下的 `` `**` `` 与后面的模板片段被当成
**幂运算符**（`"a" ** "b"`），整个表达式求值成 `NaN`；
`JSON.stringify({ expression: NaN })` 又把 `NaN` 变成 `null`，
CDP 于是报"这里期望一个字符串"。

教训：**拼给 CDP 的表达式里，注释不要用反引号**（改用引号）。
以及：给 `Runtime.evaluate` 的参数加一道 `typeof expression !== 'string'` 的校验，
比事后从 `position 19` 反查快得多。

## 六、已知边界（答辩要能说清）

1. **标注不聚合**：42 个点全部平铺，汉台区（城市中心）那一簇在默认缩放下是叠在一起的。
   这是刻意的 —— 需求是"标注我网站现有的全部景点"，聚合会把单个景点藏进数字里。
   要改善可以上 `AMap.MarkerCluster`，但那会改变"点标注 → 出卡片"的粒度。
2. **地址是"补出来"的**：数据包里只有区县，街道地址由高德逆地理编码实时查。
   拿不到就只显示区县 + 坐标。所以**断网演示时地址会退化成区县**，卡片其余部分正常。
3. **地图与图块都来自高德 CDN**：断网时地图加载不出来，页面会显示
   「高德地图脚本加载失败：网络不可达…」+ 重试按钮，**不是白屏**。
   这与 M3 的离线缓存回放不是一回事 —— 地图没有离线兜底。
4. **key 未配时不白屏**：页面显示一句说明（告诉你在 `.env` 里填哪两个变量、
   键名必须以 `VITE_` 开头、要重启开发服务器），其余部分照常。
5. **JS API key 是公开的**：这是 JS API 的固有形态。上线时应在高德控制台配**安全域名白名单**，
   而不是指望藏 key。
6. **依赖高德图块的样式**：用了 `mapStyle: 'whitesmoke'` 配站点浅色底。
   高德若调整内置样式名，这一项需要复核。
