# 汉中的地理位置与地形

汉中市位于陕西省西南部，地处秦巴山区西段，北靠秦岭，南倚米仓山（巴山），中间是汉江上游的谷地平坝。

## 四至与邻接

- 北面与宝鸡市的凤县、太白县以及西安市的周至县毗连
- 东面与安康市的宁陕县、石泉县、汉阴县和紫阳县接壤
- 南面与四川省广元市的青川县、旺苍县、朝天区，以及巴中市的南江县、通江县和达州市的万源市相连
- 西面与甘肃省陇南市的徽县、成县、康县、两当县相邻

经纬度范围在东经 105°29′14″—108°16′49″、北纬 32°08′52″—33°52′46″ 之间，东西长 261.5 千米，南北宽 192.6 千米，辖区面积 27097 平方千米。

## 地形比例

全市山地占 75.2%（其中低山 18.2%、高中山 57.0%），丘陵占 14.6%，平坝占 10.2%，地貌以山地为主。

汉中盆地东西狭长、呈椭圆形，从勉县武侯镇到洋县龙亭铺，东西长约 116 千米，南北宽 5—30 千米，市区附近宽 25—30 千米，盆地海拔在 500 米上下。

## 海拔

全市平均海拔 1128 米、平均坡度 25.4°。北部秦岭最高峰在洋县活人坪梁顶，海拔 3071 米；南部米仓山最高峰在镇巴县箭杆山，海拔 2534 米；全市最低处在西乡县茶镇南沟口，海拔 371.2 米。秦巴山体高出汉中盆地 500—2500 米。
